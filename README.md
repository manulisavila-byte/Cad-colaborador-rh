# Sistema de Cadastro e bonificação de novos colaboradores

## Descrição

Sistema responsavel pelo cadastro de novos colaboradores. No sistema, deverá ser informado o nome do colaborador e seu respectivo salario. O sistema deverá retornar uma mensagem de boas vindas dizendo ao colaborador o seu salário base juntando com o seu salário bonificado com 15%.

## Como funciona?

Além do salário mensal, o funcionário poderá receber uma bonificação de 15% sobre o salário, de acordo com seu desempenho e cumprimento das metas estabelecidas pela empresa. A bonificação será avaliada mensalmente e poderá variar conforme os resultados alcançados e a qualidade do trabalho realizado.
